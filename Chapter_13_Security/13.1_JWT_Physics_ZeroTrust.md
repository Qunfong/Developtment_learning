## 1. The Physics of the Token


### 1.1 The Signature Tax
. **RSA-2048:** On a standard core, one verification takes **~1ms**.
. **Impact:** In a Ledger doing 1M RPS, you need **1,000 dedicated CPU cores** just for math. 
. **The Principal Fix:** Use **EdDSA**. It is 10x faster and has smaller keys, reclaiming 90% of your security budget.


---


## 2. Source Archaeology: JWKS and Rotation


A Principal never hardcodes a public key. We use **JWKS (JSON Web Key Set)** for hitless rotation.


> [!abstract] The Mechanics: Key Discovery
. **Step 1:** The Identity Provider (IDP) publishes keys at a URL.
. **Step 2:** Pods fetch and cache these in a **Caffeine L1 Cache**.
. **Step 3:** Tokens are verified against the cached key ID (`kid`).


---


## 3. Principal Implementation: The Identity Guard


```java
// Principal Level: Zero-Trust Identity Guard
public class IdentityGuard {
    // 1. L1 Cache for Public Keys
    private final LoadingCache(String, PublicKey) keyCache = Caffeine.newBuilder()
        .expireAfterWrite(Duration.ofHours(1))
        .build(kid -> fetchFromIdp(kid));

    public boolean verify(String jwt) {
        String kid = extractKid(jwt); 
        PublicKey key = keyCache.get(kid);

        // 2. Perform Math on a Virtual Thread
        return crypto.verify(jwt, key);
    }
}
```
