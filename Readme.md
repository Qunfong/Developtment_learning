## 🛠️ Viewing Diagrams (PlantUML)

This course uses **PlantUML** for all architectural diagrams to ensure high-fidelity rendering. To view the diagrams correctly in Obsidian or your IDE, follow these steps:

### For Obsidian Users:
1. Install the **PlantUML** community plugin.
2. In the plugin settings, ensure the **Server URL** is set to:
   `https://www.plantuml.com/plantuml`
3. The diagrams will now automatically render within the ```plantuml ... ``` blocks.
